# Contribuir

## Principios

1. No presente una hipotesis o una visualizacion cualitativa como una medicion de desempeno.
2. Conserve los archivos fuente editables ademas de las exportaciones para fabricacion.
3. Documente unidades, material, revision CAD, configuracion de impresion y metodo de prueba.
4. Etiquete las variantes con una version nueva y mantenga trazabilidad con la version de partida.

## Cambios de geometria

Incluya el archivo editable de Fusion 360 u otro formato fuente abierto, el STL exportado, dimensiones principales y una nota que describa el cambio. Si el cambio afecta ajuste, resistencia o aerodinamica, incluya un protocolo y datos de validacion.

## Resultados de prueba

Para CFD, publique geometria, malla, condiciones de frontera, modelo de turbulencia, regimen de flujo, criterios de convergencia y resultados comparativos. Para ensayo fisico, publique instrumento, calibracion, condiciones ambientales, incertidumbre y datos crudos.
