# README assets

- `ojiva-alcedo-hero.png`: editorial illustration for the repository header. It is illustrative only and does not replace the CAD files or constitute aerodynamic evidence.
- `ojiva-alcedo-hero-v2.png`: README header artwork. Its ojiva form is based on a direct render of the released STL and is composed parallel to a flying *Alcedo atthis* beak to communicate the biological inspiration. The bird and artwork are illustrative context, not technical or aerodynamic evidence.
- `ojiva-alcedo-cover-v3.png`: final README cover layout, pairing the v2 source visual with project title and descriptive context. It is illustrative and does not replace the released CAD/STL or constitute technical evidence.
- `ojiva-alcedo-icon.png`: project icon used at the top of both README files.
